FAQ

Common questions

What kinds of games do you develop?
We focus on casual 2D games, browser and HTML5 games, Telegram Mini App games and gamified experiences for websites and products.
Can you build a playable prototype first?
Yes. Starting with a prototype or MVP is often the best way to test the core idea before investing in full production.
Do you develop games for mobile devices?
Yes. We build games that run well on mobile, including browser-based and Telegram Mini App formats.
Can you create browser games?
Yes. Browser and HTML5 games let players start instantly, with nothing to install.
Can you add leaderboards or player accounts?
Yes. We build the backend systems behind gameplay, including leaderboards, player profiles and in-game economies.
Can you continue development after launch?
Yes. We can keep improving a game after release, or pick up and extend an existing project.
