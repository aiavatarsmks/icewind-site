Preguntas frecuentes

Preguntas habituales

¿Qué diferencia hay entre un sitio web y una aplicación web?
Un sitio web sirve sobre todo para presentar información. Una aplicación web permite a las personas hacer cosas: iniciar sesión, gestionar datos, ejecutar flujos de trabajo e interactuar con la lógica. Creamos aplicaciones y los sitios web que las acompañan.
¿Se puede desarrollar un MVP?
Sí. Definimos una primera versión enfocada que demuestre la idea principal y, a partir de ahí, la hacemos crecer.
¿Se puede integrar con nuestro software actual?
Sí. Nos conectamos a las herramientas, CRM y servicios que ya usas a través de sus API, siempre que lo permitan.
¿Se pueden sustituir procesos basados en hojas de cálculo?
Sí. Pasar un proceso frágil basado en hojas de cálculo a una aplicación en condiciones es una de las cosas que más hacemos.
¿Cómo se define la primera versión?
Buscamos la versión útil más pequeña que resuelva el problema real, acordamos el alcance y dejamos margen para ampliarla.
¿Puede crecer la aplicación después del lanzamiento?
Sí. Construimos sobre una base pensada para ampliarse, de modo que se pueden añadir funciones nuevas a medida que aprendes.
